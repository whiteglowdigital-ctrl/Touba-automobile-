# Touba Automobile — maquette du site

Site en ligne : https://whiteglowdigital-ctrl.github.io/Touba-automobile-/

- La racine du dépôt contient le site prêt à l'emploi (publié par GitHub Pages).
- `source/` contient le code React + Tailwind (voir `source/README.md`).

## Mettre à jour le site

```bash
cd source
npm install
npm run build        # génère source/dist/
```

Puis copier le contenu de `source/dist/` à la racine du dépôt (remplacer `index.html` et `assets/`) et pousser.
